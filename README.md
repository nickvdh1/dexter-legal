# Dexter — legal documents

The Privacy Policy and Terms of Use for **Dexter**, an unofficial Pokémon GO
companion app for iOS. Published with GitHub Pages so the App Store listing and
the app's paywall have stable, functional URLs to point at.

- Privacy Policy — https://nickvdh1.github.io/dexter-legal/privacy/
- Terms of Use — https://nickvdh1.github.io/dexter-legal/terms/

Plain static HTML, one stylesheet, no build step. Edit the files and push; Pages
redeploys. When either document changes, update the date at the top of it — both
say "Last updated" and reviewers do check.

Dexter is an unofficial fan project. It is not affiliated with, endorsed by or
sponsored by Niantic, Inc., Nintendo, Creatures Inc., GAME FREAK Inc. or The
Pokémon Company.
